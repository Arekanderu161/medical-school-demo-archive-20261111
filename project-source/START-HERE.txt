ПРАКТИКА — ДЕМОНСТРАЦИЯ ВЕБ-ШКОЛЫ

1. РАСПАКОВКА И ЗАПУСК
Приложение запускается через локальный сервер (не открывайте index.html двойным щелчком).
Установите Node.js 22 или 24 (вместе с npm).
Откройте терминал в папке medical-school-demo и выполните:
  npm ci
  npm run dev
Откройте http://127.0.0.1:3000 в браузере того же компьютера.
Для остановки сервера нажмите Ctrl+C в терминале.
Ключи сервисов, файл .env и Telegram не нужны.

2. КАК ПОСМОТРЕТЬ ДЕМО
Выберите тариф «Вместе с автором» → «Открыть демо-доступ» → «Продолжить обучение».
В уроке запустите интерактивный пример и отметьте урок пройденным.
Задайте вымышленный вопрос под уроком → перейдите в «Режим автора» → ответьте → вернитесь в урок.
Пособие открывается отдельной страницей. Нажмите «Печать / сохранить PDF» и выберите сохранение в PDF в диалоге браузера.
«Сбросить демо» внизу страницы очищает только данные этой демонстрации в текущем браузере.

3. СОСТАВ ПРОЕКТА
src/main.tsx, src/App.tsx, src/school/ — действующее приложение школы.
dist/ — готовая статическая сборка для публикации на веб-хостинге. Это публичное демо: не добавляйте в него реальные данные учеников или пациентов.
package.json, package-lock.json — зависимости и команды проекта.
tests/ — модульные (Vitest) и браузерные (Playwright) автоматические проверки.
AGENTS.md — правила проекта, продуктовые ограничения и целевой стек рабочей платформы.
CODEX_PLAN.md — статус демо и пошаговый план дальнейшей разработки (Фазы 1–3).
CLIENT-LETTER.txt — сопроводительное письмо для показа демо клиентке.

4. ПРОВЕРКИ И ПУБЛИКАЦИЯ
  npm test
  npm run typecheck
  npm run build
  npm run test:e2e
Для браузерных тестов требуется установленный Google Chrome.
Для локального просмотра готовой сборки: npm run preview (адрес покажет терминал).
Для публикации передайте содержимое dist/ администратору статического веб-хостинга; маршруты используют hash.
Локальный адрес 127.0.0.1 не является публичной ссылкой для клиентов.

5. ЧТО ПОКА НЕ ПОДКЛЮЧЕНО (ЭТАП 1 — ПЕРЕХОД К РАБОЧЕЙ ПЛАТФОРМЕ)
Реальная оплата, email-вход, серверный контроль доступа (NestJS + PostgreSQL + Prisma), видеохостинг (Kinescope), персональная серверная генерация PDF (S3) и настоящие видеолекции подключаются на следующем этапе после согласования демо.
Плеер показывает интерактивный макет слайдов, а не медицинскую запись.
Название, программа, цены, сроки и лимиты обратной связи — предварительные примеры.
Данные демо сохраняются локально в текущем браузере.
Режим автора открыт для демонстрации и не является защищённой административной панелью.
Это прототип для согласования с клиенткой, а не готовая к продажам платформа.
